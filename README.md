# Bitácora de aprendizaje web

Este repositorio reúne apuntes introductorios sobre desarrollo web y herramientas de programación. Es un espacio de aprendizaje que se irá completando conforme avance el estudio.

## Contenido

- [`bitacora1.txt`](./bitacora1.txt): conceptos básicos de HTML, CSS y JavaScript; diferencias entre editor e IDE; y una introducción a los archivos README.
- [`bitacora2.md`](./bitacora2.md): notas sobre la creación y publicación de este repositorio con Git y GitHub.

## Tecnologías y herramientas

- **HTML:** estructura y contenido de páginas web.
- **CSS:** presentación y diseño.
- **JavaScript:** programación e interactividad en la web.
- **Markdown:** formato sencillo para escribir documentación.
- **Git y GitHub:** control de versiones y publicación del repositorio.

## Cómo consultar los apuntes

Abre los archivos de bitácora desde GitHub o descarga/clona el repositorio:

```bash
git clone https://github.com/theramsom/web.git
```

## Estado del proyecto

Repositorio educativo personal en construcción. Los apuntes pueden actualizarse y ampliarse a medida que se incorporen nuevos temas.
